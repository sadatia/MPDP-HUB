# MPDP-HUB 🏗️
### Project Launch Page | Penta-Ocean / TOA JV

This is a centralized web dashboard for the **MPDP Phase-1** construction project. it provides a unified interface for site engineers and staff to access in-house web applications, administrative resources, and OT (Overtime) applications.
